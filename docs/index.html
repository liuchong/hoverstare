AI code review that actually reads your repo.

HoverStare reviews pull requests with repository context, read-only investigation tools, multi-pass voting, and precise inline comments that keep tracking findings across commits.

Reviewer loop

Open context, vote, verify, comment.

  1. 1Fetch PR diff and base branch context
  2. 2Run parallel review passes with read-only tools
  3. 3Cluster votes and verify low-confidence findings
  4. 4Anchor inline comments and resolve fixed threads

Signal first

Built for reviews that need the rest of the codebase.

Repo-aware, not diff-only

The reviewing model can inspect files, grep call sites, and compare against the base branch before it reports a defect.

Voting plus verification

Independent passes look for correctness, concurrency, and security issues, then a verifier checks lonely findings before publication.

Precise inline comments

Reported line numbers are validated against the real diff and snapped to a valid anchor so comments land where reviewers expect.

Incremental by design

Hidden fingerprints follow findings across pushes, letting HoverStare review the delta and mark fixed issues without repeats.

Fail-open Analysis trouble should not block CI.
BYOK Use Anthropic or an OpenAI-compatible endpoint.
Stateless Review state lives in GitHub comments and metadata.

Two minutes

Add HoverStare to a repository.

Create `.github/workflows/hoverstare.yml`, add an LLM key as a repository secret, and let pull requests trigger reviews.

.github/workflows/hoverstare.yml 
name: HoverStare
on:
  pull_request:
    types: [opened, reopened, synchronize]

permissions:
  contents: read
  pull-requests: write
  statuses: write

jobs:
  hoverstare:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: liuchong/hoverstare@v0.0.5
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          OPENAI_API_KEY: ${{ secrets.HOVERSTARE_LLM_KEY }}
          OPENAI_BASE_URL: ${{ vars.HOVERSTARE_LLM_BASE_URL }}
          HOVERSTARE_MODEL: ${{ vars.HOVERSTARE_MODEL }}

Commands

Talk to it in the PR.

@hoverstare review Force a fresh review when the conversation needs another pass.
@hoverstare explain Ask for a plain-language explanation inside a review thread.
@hoverstare help Print the supported command list for the repository.
